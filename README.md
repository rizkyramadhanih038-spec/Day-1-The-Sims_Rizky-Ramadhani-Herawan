Rangkuman Materi Workshop: 
Workshop kali ini membahas dua hal: cara pakai AI dan cara mengelola perubahan pakai GitHub.

Prompt Engineering

Prompt adalah instruksi yang kita kasih ke AI. Hasilnya bagus atau nggak sangat tergantung konteks yang kita berikan. Kalau cuma nulis "buatkan task planner", hasilnya generik. Tapi kalau prompt-nya lengkap — ada Role (AI berperan sebagai siapa), Task (tugasnya apa), Context (kebutuhan dan batasannya), dan Format (hasilnya mau seperti apa) — hasilnya jauh lebih tepat dan langsung bisa dipakai. Batasan juga penting, misalnya "pakai HTML, CSS, dan JavaScript murni, jangan pakai library".

Git dan GitHub

Git adalah version control system, alat untuk melacak siapa, kapan, dan apa saja yang sudah diubah dalam suatu file. Git diciptakan oleh Linus Torvalds tahun 2005. Ada tiga area yang perlu dipahami: working directory (file yang sedang dikerjakan), staging area (perubahan yang disiapkan untuk di-commit), dan git directory (tempat Git menyimpan seluruh data proyek).

Bedanya dengan GitHub: Git itu alatnya dan berjalan lokal, sedangkan GitHub adalah platform web untuk menyimpan repository secara online dan berkolaborasi.


Poin - Poin Penting: 
1. Prompt yang spesifik dan ada konteksnya hasilnya jauh lebih bagus daripada prompt seadanya
2. Git itu alat version control yang jalan di lokal, GitHub itu platform online-nya. Beda ya
3. Jangan lupa `git add` dulu sebelum `git commit`, dan selalu commit dengan pesan yang jelas
4. Biasakan commit dan push secara rutin, jangan numpuk di akhir
5. Setup Git, VS Code, dan SSH key dari awal biar kerjaan selanjutnya nggak ribet
6. Hasil dari AI jangan langsung dipercaya, coba dulu baru dianggap berhasil


Pendapat Pribadi:

Bagian prompt engineering juga gampang dicerna karena langsung dikasih contoh nyata dari prompt yang jelek sampai yang lengkap.

Masukannya mungkin lebih ke porsi praktik aja sih, buat anak-anak maba masih banyak yang belum pernah buka terminal atau nyentuh Git sama sekali, jadi kalau ada sesi hands-on tambahan atau panduan step by step yang bisa diikutin sendiri bakal lebih ngebantu. Selebihnya gacor kok, penyampaiannya enak dan nggak bikin ngantuk.
